# Sample Session (Template)

This is not a real training session — it's a template showing the folder
structure used under every real session in `Sessions/`.

```
Sample-Session/
  Artifacts/            <- session owner materials go here (slides, docs, sample code)
  <ParticipantName>/    <- one folder per participant, for their assignment submission
    placeholder.md
```

Git doesn't track empty folders, so the real `Sessions/<session-name>/<YourName>/`
folders won't appear until you add a file to them. This template exists (with a
placeholder file in each participant folder) purely so everyone can see their
own named folder right after cloning.

## What to do

1. Find your name under `Sample-Session/`.
2. Delete `placeholder.md` inside it once you understand the structure.
3. For your actual assignments, use the matching folder under
   `Sessions/<session-name>/<YourName>/`, not this one.
