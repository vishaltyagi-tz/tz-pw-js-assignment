# API Setup (Bonus)

**Optional Session J** · Self-paced, anytime after Week 15 · Optional · Module 3: Test Architecture
**Session Owner:** Self-study

## Learning Objectives

Basic API seeding using Playwright's request context, setting up test data via API before UI tests, authentication tokens, request/response handling.

## For Session Owners

- Prepare talking points and any live-demo code around the objectives above.
- Add supporting material (slides, sample code, recordings, cheat sheets) to this `Artifacts` folder.
- Review participant submissions in the sibling `../<ParticipantName>/` folders after the session.

## Weekly Assignment (Homework)

1) Use Playwright's `request` context to make a GET request to a public API and log the response.

2) Create a test that seeds test data via API call before running a UI verification step.

3) Write a helper function that authenticates via API and stores the token for subsequent requests.
