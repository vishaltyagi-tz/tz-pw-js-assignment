# Sample Submission — Week 1

This folder shows what a completed Week 1 submission looks like: plain `.js` files,
run directly with `node <file>.js`, with clear console output for each task.

It's a reference for **structure and naming**, not something to copy-paste — write
your own values (name, tool, date) and, once submissions start, place your actual
files in your own participant folder:

```
Sessions/Week-01-Environment-Setup-First-Line-of-Code/<YourName>/
    hello.js
    about-me.js
```

Run each file the same way shown here:

```
node hello.js
node about-me.js
```

See `../Session-Guide.md` and `../Basic-Setup.docx` for the full task list.
