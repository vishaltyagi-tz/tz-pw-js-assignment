# Complex Popups

**Optional Session F** · Self-paced, anytime after Week 11 · Optional · Module 2: Playwright Core
**Session Owner:** Self-study

## Learning Objectives

Handling IFrames using `frameLocator()`, browser dialogs and alerts using `page.on('dialog')`, accepting/dismissing alerts, nested frames.

## For Session Owners

- Prepare talking points and any live-demo code around the objectives above.
- Add supporting material (slides, sample code, recordings, cheat sheets) to this `Artifacts` folder.
- Review participant submissions in the sibling `../<ParticipantName>/` folders after the session.

## Weekly Assignment (Homework)

1) Write a test that interacts with elements inside an IFrame using `frameLocator()` on a practice site.

2) Handle a JavaScript alert dialog using `page.on('dialog')` - accept it and verify the page state changes accordingly.

3) Create a test scenario that dismisses a confirm dialog and verifies the 'Cancel' action was processed correctly.
