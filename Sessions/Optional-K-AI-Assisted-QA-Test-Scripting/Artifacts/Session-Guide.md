# AI Tools for Test Automation Awareness

**Optional Session K** · Self-paced, anytime after Week 15 · Optional · AI-Assisted QA & Test Scripting
**Session Owner:** Self-study

## Learning Objectives

Using AI coding assistants (e.g. GitHub Copilot, Claude, ChatGPT) to generate/refactor test scripts, prompt engineering for writing test cases & locators, AI-assisted debugging of failing tests, self-healing locators concept, limitations & risks of AI-generated code (hallucinated selectors, outdated APIs, over-trusting output), always reviewing AI output before committing.

## For Session Owners

- Prepare talking points and any live-demo code around the objectives above.
- Add supporting material (slides, sample code, recordings, cheat sheets) to this `Artifacts` folder.
- Review participant submissions in the sibling `../<ParticipantName>/` folders after the session.

## Weekly Assignment (Homework)

1) Use an AI assistant to generate a new Playwright test scenario (e.g. 'add to cart and remove item') from a plain-English prompt, then manually review and correct any inaccurate locators or logic before running it.

2) Paste one of your own failing tests and its error message into an AI assistant to get a suggested fix; apply the fix only after understanding why it works, and note in a comment what the AI got wrong or right.

3) Write a short reflection (5-6 sentences) on one risk of blindly trusting AI-generated test code and one way you verified the AI's suggestion before using it.
