# Branching & Merging

**Optional Session B** · Self-paced, anytime after Week 5 · Optional · Git & Version Control
**Session Owner:** Self-study

## Learning Objectives

`git branch`, `git checkout`/`git switch`, creating feature branches, `git merge`, understanding and resolving merge conflicts.

## For Session Owners

- Prepare talking points and any live-demo code around the objectives above.
- Add supporting material (slides, sample code, recordings, cheat sheets) to this `Artifacts` folder.
- Review participant submissions in the sibling `../<ParticipantName>/` folders after the session.

## Weekly Assignment (Homework)

1) Create a new branch `feature/arrays-practice`, make a change to your Week 5 script, and commit it on that branch.

2) Merge the branch back into `main`/`master` and confirm the change appears in history.

3) Deliberately create a merge conflict (edit the same line on two branches) and practice resolving it manually, then commit the resolution.

## Submission Instructions

- Save your files inside `Sessions/Optional-B-Branching-Merging/<YourName>/` (your own participant folder).
- Use plain, descriptive filenames as instructed above.
- Do not commit `node_modules/` or other generated folders.
