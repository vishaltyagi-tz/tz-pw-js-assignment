# Project Config

**Optional Session D** · Self-paced, anytime after Week 7 · Optional · Module 2: Playwright Core
**Session Owner:** Self-study

## Learning Objectives

Understanding package.json structure, npm scripts, node_modules folder, dependency management, devDependencies vs dependencies, npm install/update basics.

## For Session Owners

- Prepare talking points and any live-demo code around the objectives above.
- Add supporting material (slides, sample code, recordings, cheat sheets) to this `Artifacts` folder.
- Review participant submissions in the sibling `../<ParticipantName>/` folders after the session.

## Weekly Assignment (Homework)

1) Open your Playwright project's `package.json` and document (in comments) what each section means: name, scripts, dependencies, devDependencies.

2) Add a custom npm script (e.g., `"test:smoke": "npx playwright test --grep @smoke"`) and run it from the terminal.

3) Delete `node_modules`, run `npm install`, and explain in a comment why this works and when you'd need to do this.

## Submission Instructions

- Save your files inside `Sessions/Optional-D-Project-Config/<YourName>/` (your own participant folder).
- Use plain, descriptive filenames as instructed above.
- Do not commit `node_modules/` or other generated folders.
